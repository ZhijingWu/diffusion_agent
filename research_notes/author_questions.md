# Author Questions

These are ranked by value. The outreach email should ask at most 2–3.

## Q1 — Intended execution semantics of \(A_{ij}\)  **[highest priority]**

The released GSM8K path stores and trains on an \(N\times N\) adjacency matrix, but `Graph` flattens that mask and the effective `init_potential_edges()` builds only non-self edges before the execution loop zips the two sequences.

**Question:**
> Is the intended execution semantics exactly \(A_{ij}=1\Rightarrow i\to j\), or is the released mask-to-edge remapping intentional?

Why this is strong:
- deterministic source-level mechanism;
- exhaustive probe;
- 603-record quantified impact;
- controlled repair restores fidelity.

## Q2 — What should the Proxy's cost target mean?  **[high priority]**

Phase-1 source computes:

```python
cost = sum(sum(row) for row in topology_matrix)
```

while utility is generated by actually executing `Graph(fixed_spatial_masks=topology_matrix)`.

**Question:**
> Is the intended multi-objective cost target raw graph edge count, actual executed edge count, or token consumption? How should this be reconciled with runtime remapping/cycle filtering?

Why this is strong:
- 300/300 exact data check;
- directly relevant to the paper's cost-efficiency story.

## Q3 — Final decision node and topology causality  **[high priority, but exploratory]**

After agent rounds, the released runtime connects every agent to the final decision node.

**Question:**
> Was the final decision node intentionally designed to receive every agent's output regardless of the generated spatial topology? If so, how do you think about isolating the causal contribution of intermediate topology in evaluation?

Why this is interesting:
- canonical execution changes all 50 executed graphs but leaves all 50 correctness outcomes unchanged in one matched sample;
- sink-only ablation creates two outcome disagreements, but evidence is still exploratory.

## Q4 — Proxy topology sensitivity in homogeneous teams  **[secondary]**

With four identical MathSolver profiles, the trained Proxy changes by only about \(10^{-8}\)–\(10^{-7}\) across very different topologies.

**Question:**
> In the homogeneous-agent GSM8K setting, what graph-structural signal is expected to let the Proxy rank candidates, and did you observe similar sensitivity in your original checkpoints?

Why secondary:
- technically important;
- related ideas may already exist in later work, so it should not be framed as our primary novelty.
